# Marca — David Saavedra | Propiedades

- `LOGO DS PROPIEDADES.ai` — **archivo maestro** (Adobe Illustrator). Fuente de verdad del monograma.
- `public/brand/` — assets digitales derivados del maestro, sin modificar la geometría:
  - `logo.svg` — monograma oficial (marfil `#F3EEE7` + dorado `#E4B77B`). Para fondos oscuros.
  - `logo-dark.svg` — mismo vector con las letras en tinta `#0F0F0E`. Para fondos claros.
  - `symbol.svg` — monograma oficial centrado sobre fondo `#0F0F0E` (512×512). Favicon y avatar.

Derivación: trazados exportados del `.ai` (PDF compatible) a SVG con sus coordenadas
originales; `viewBox` recortado al ArtBox de Illustrator y colores expresados en hexadecimal.
Para actualizar el logo, exportar desde el `.ai` y reemplazar estos archivos.
